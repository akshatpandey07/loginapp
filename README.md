# employee-management-system - HRMS (Human Resource Management System)

A complete enterprise-level HRMS application built with React, Node.js, Express, and PostgreSQL.

## Features

- **Authentication** - Secure Login/Signup with JWT
- **Employee Management** - Create, view, search, paginate employees
- **Leave Management** - Apply, approve, reject leaves
- **Asset Management** - Allocate and track company assets
- **Attendance Tracking** - Present/Absent/Late, Online/Offline/Hybrid
- **Payroll System** - Salary calculation with TDS, PF, ESIC deductions
- **Notifications** - Alerts for leave and asset assignments
- **Audit Trail** - Track all data changes
- **Analytics Dashboard** - Charts for attendance, salary, leave, assets
- **Production Ready** - Logging, error handling, validation, pagination

## Tech Stack

**Frontend:** React, React Router, Axios, Recharts
**Backend:** Node.js, Express, JWT, Bcrypt, Multer, Joi, Winston
**Database:** PostgreSQL

## Installation

### Backend
cd backend
npm install
npm run dev 

### Frontend
cd frontend
npm install
npm start 

## API Endpoints

- `/api/v1/auth` - Login/Signup
- `/api/v1/employees` - Employee CRUD
- `/api/v1/leaves` - Leave Management
- `/api/v1/assets` - Asset Management
- `/api/v1/payroll` - Payroll & Attendance Analytics
